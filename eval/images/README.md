# ภาพสำหรับชุดทดสอบ Vision

| ไฟล์ | เนื้อหา | บริการที่ควรแนะนำ (ตามคลังความรู้) | ชุดทดสอบ |
| :--- | :--- | :--- | :--- |
| `01_bsod.png` | หน้าจอฟ้า Windows (Stop code: CRITICAL_PROCESS_DIED) | S03 เริ่มต้น 800 บาท | V01 (หลัก) |
| `02_no_bootable_device.png` | หน้าจอดำ "No bootable device" | S01 ตรวจเช็คฟรี → S02 / S12 | V02 (หลัก) |
| `03_cracked_screen.jpg` | จอโน้ตบุ๊กแตก มีเส้นสีและจุดดำ | S08 ค่าแรง 500 บาท ไม่รวมอะไหล่ | V03 (หลัก) |
| `04_keyboard.jpg` | คีย์บอร์ดโน้ตบุ๊กปุ่ม G หลุด | S05 เริ่มต้น 300 บาท | V04 (หลัก) |
| `05_router_red_light.jpg` | Router ไฟ LOS สีแดง | S09 800 บาท / ติดต่อผู้ให้บริการอินเทอร์เน็ต | V05 (หลัก) |
