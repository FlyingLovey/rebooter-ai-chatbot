## S01 ตรวจเช็คอาการ
- ราคา: ฟรี
- ช่างตรวจอาการและแจ้งราคาให้ลูกค้าตัดสินใจก่อนเสมอ หากลูกค้าไม่ซ่อม ไม่มีค่าใช้จ่ายใดๆ
- ระยะเวลาตรวจ: ประมาณ 30–60 นาที หรือภายในวันเดียวกัน

## S02 ติดตั้ง Windows 10/11 พร้อมไดรเวอร์
- ราคา: 500 บาท
- รวมติดตั้งไดรเวอร์ อัปเดตระบบ และโปรแกรมพื้นฐาน (เบราว์เซอร์ โปรแกรมอ่าน PDF)
- ลูกค้าต้องมีลิขสิทธิ์ Windows ของตนเอง ร้านไม่ติดตั้งซอฟต์แวร์ละเมิดลิขสิทธิ์
- ข้อมูลเดิมในไดรฟ์ C จะถูกลบ แนะนำใช้บริการสำรองข้อมูล (S17) ก่อน
- ระยะเวลา: 2–3 ชั่วโมง

## S03 ตรวจซ่อมอาการเปิดไม่ติด / จอฟ้า (BSOD)
- ราคา: เริ่มต้น 800 บาท (ราคาสุดท้ายแจ้งหลังตรวจเช็คฟรี ก่อนเริ่มซ่อม)
- ครอบคลุม: เปิดไม่ติด เปิดติดแต่ไม่ขึ้นภาพ จอฟ้า รีสตาร์ทเอง บูตวนลูป
- ไม่รวมค่าอะไหล่ หากต้องเปลี่ยนอะไหล่ ช่างจะแจ้งราคาอะไหล่ก่อนเสมอ
- ระยะเวลา: 1–3 วันทำการ

## S04 กู้ข้อมูลเบื้องต้น
- ราคา: เริ่มต้น 1,000 บาท
- ครอบคลุม: ไฟล์ถูกลบ ฟอร์แมตไดรฟ์ พาร์ติชันหาย บนไดรฟ์ที่ตัวฮาร์ดแวร์ยังทำงานได้
- ไม่รับกู้ข้อมูลจากไดรฟ์ที่เสียหายทางกายภาพ (หัวอ่านเสีย ตกน้ำ) — ร้านจะแนะนำให้ติดต่อศูนย์กู้ข้อมูลเฉพาะทาง
- ไม่รับประกันว่าจะกู้ได้ 100% หากกู้ไม่ได้เลย ไม่เก็บค่าบริการ

## S05 ซ่อมคีย์บอร์ดโน้ตบุ๊ก
- ราคา: เริ่มต้น 300 บาท
- ครอบคลุม: ปุ่มหลุด ปุ่มค้าง พิมพ์ไม่ติดบางปุ่ม ทำความสะอาดใต้แป้น
- หากต้องเปลี่ยนแผงคีย์บอร์ดทั้งชุด คิดค่าอะไหล่เพิ่มตามรุ่น (แจ้งก่อนซ่อม)

## S06 Remote Support ผ่าน AnyDesk
- ราคา: 250 บาท/ครั้ง (ไม่เกิน 60 นาทีต่อครั้ง)
- เหมาะกับ: ปัญหาซอฟต์แวร์ ตั้งค่าโปรแกรม ตั้งค่าอีเมล ไวรัสเบื้องต้น
- ไม่เหมาะกับ: ปัญหาฮาร์ดแวร์ หรือเครื่องที่เปิดไม่ติด / เข้าอินเทอร์เน็ตไม่ได้
- ชำระเงินก่อนเริ่มเชื่อมต่อ ลูกค้าเป็นผู้กดยินยอมการเชื่อมต่อเองทุกครั้ง

## S07 ติดตั้ง RAM
- ราคา: 200 บาท (กรณีลูกค้านำ RAM มาเอง)
- ร้านช่วยตรวจว่า RAM เข้ากับเครื่องได้หรือไม่ก่อนติดตั้งโดยไม่มีค่าใช้จ่าย

## S08 เปลี่ยนหน้าจอโน้ตบุ๊ก
- ราคา: ค่าแรง 500 บาท **ไม่รวมค่าอะไหล่หน้าจอ**
- ราคาจอขึ้นกับรุ่นของเครื่อง ช่างจะแจ้งราคาอะไหล่จริงหลังตรวจรุ่นเครื่อง แชทบอทไม่ประเมินราคาอะไหล่เอง
- อาการที่เข้าข่าย: จอแตก จอเป็นเส้น จอมีจุดดำ จอกะพริบ
- ระยะเวลา: 1–5 วันทำการ (ขึ้นกับการสั่งอะไหล่)

## S09 ติดตั้ง / ตั้งค่าเครือข่าย Wi-Fi และ Router
- ราคา: 800 บาท
- ครอบคลุม: ตั้งค่า Router ใหม่ ตั้งรหัส Wi-Fi ตั้งค่า Mesh แก้ไฟแดงกะพริบ เน็ตหลุดบ่อย
- กรณีสัญญาณจากผู้ให้บริการอินเทอร์เน็ตขัดข้อง ร้านจะแนะนำให้ติดต่อผู้ให้บริการโดยตรง

## S10 ล้างเครื่องและเปลี่ยนซิลิโคน
- ราคา: โน้ตบุ๊ก 450 บาท / PC 350 บาท
- เหมาะกับอาการ: เครื่องร้อน พัดลมดัง เครื่องดับเองเมื่อใช้งานหนัก
- ระยะเวลา: ภายในวันเดียวกัน

## S11 กำจัดไวรัส / มัลแวร์
- ราคา: 400 บาท
- ครอบคลุม: ไวรัส มัลแวร์ แอดแวร์ ป๊อปอัปโฆษณา เบราว์เซอร์ถูกเปลี่ยนหน้าแรก
- กรณีแรนซัมแวร์ (ไฟล์ถูกเข้ารหัส): กำจัดได้ แต่ไม่รับประกันการกู้ไฟล์ที่ถูกเข้ารหัส

## S12 ติดตั้ง SSD พร้อมย้ายระบบ
- ราคา: ค่าแรง 400 บาท ไม่รวมค่า SSD
- ย้ายระบบและข้อมูลเดิมไปยัง SSD ใหม่ (Clone) ใช้งานต่อได้ทันที

## S13 เปลี่ยนแบตเตอรี่โน้ตบุ๊ก
- ราคา: ค่าแรง 300 บาท ไม่รวมค่าแบตเตอรี่
- อาการที่เข้าข่าย: แบตเสื่อม ชาร์จไม่เข้า แบตบวม (แบตบวมควรหยุดใช้งานทันที)

## S14 ติดตั้งโปรแกรม
- ราคา: 150 บาท/โปรแกรม
- ติดตั้งเฉพาะโปรแกรมที่ลูกค้ามีลิขสิทธิ์ถูกต้อง หรือโปรแกรมฟรี

## S15 ประกอบคอมพิวเตอร์
- ราคา: 700 บาท (ลูกค้าซื้ออุปกรณ์มาเอง)
- รวมจัดสายไฟ ทดสอบระบบ และติดตั้ง Windows หากลูกค้ามีลิขสิทธิ์ (ไม่คิดค่าติดตั้ง OS เพิ่ม)

## S16 ตั้งค่าเครื่องพิมพ์ / สแกนเนอร์
- ราคา: 300 บาท
- ครอบคลุม: ติดตั้งไดรเวอร์ ตั้งค่าพิมพ์ผ่าน Wi-Fi แก้อาการ Printer Offline

## S17 สำรองข้อมูล (Backup)
- ราคา: 300 บาท สำหรับข้อมูลไม่เกิน 500 GB
- ลูกค้านำไดรฟ์ปลายทางมาเอง หรือซื้อไดรฟ์จากร้านตามใบเสนอราคา

## S18 ซ่อมพอร์ตชาร์จ / แจ็ค DC
- ราคา: เริ่มต้น 600 บาท
- อาการที่เข้าข่าย: เสียบสายชาร์จแล้วไฟไม่เข้า ต้องขยับสายถึงจะชาร์จ

## S19 ตั้งค่าอีเมล / Outlook / Microsoft 365
- ราคา: 250 บาท
- ทำได้ทั้งหน้าร้านและผ่าน Remote Support

## S20 บริการนอกสถานที่ (On-site)
- ค่าเดินทาง: 300 บาท ภายในรัศมี 10 กม. จากร้าน บวกค่าบริการตามรายการที่ใช้จริง
- นอกรัศมี 10 กม. ไม่ให้บริการ On-site แนะนำใช้ Remote Support หรือนำเครื่องมาที่ร้าน
- ต้องนัดหมายล่วงหน้าอย่างน้อย 1 วัน

## นโยบาย P01 การแจ้งราคาก่อนซ่อม
- ตรวจเช็คอาการฟรีเสมอ และแจ้งราคาค่าบริการ + ค่าอะไหล่ให้ลูกค้ายืนยันก่อนลงมือซ่อมทุกครั้ง
- หากระหว่างซ่อมพบปัญหาเพิ่ม ช่างจะติดต่อขออนุมัติก่อน ไม่ซ่อมเพิ่มโดยไม่ได้รับอนุญาต

## นโยบาย P02 การรับประกันงานซ่อม
- งานฮาร์ดแวร์ (เปลี่ยนอะไหล่ ซ่อมวงจร): รับประกัน 90 วัน
- งานซอฟต์แวร์ (ลง OS กำจัดไวรัส ตั้งค่าโปรแกรม): รับประกัน 15 วัน
- การรับประกันครอบคลุมเฉพาะอาการเดิมที่ซ่อม
- ประกันสิ้นสุดทันทีหาก: เครื่องตกหรือตกน้ำ มีการแกะเครื่องโดยผู้อื่น ติดตั้งโปรแกรมละเมิดลิขสิทธิ์ภายหลัง
- **ระยะเวลารับประกันเป็นมาตรฐานเดียวกันทุกลูกค้า ไม่สามารถขยายหรือเปลี่ยนแปลงเป็นรายกรณีได้**

## นโยบาย P03 การคืนเงิน
- หากร้านไม่สามารถแก้ไขอาการที่แจ้งซ่อมได้ ยินดีคืนเงินค่าบริการ 100%
- ค่าอะไหล่ที่ติดตั้งแล้วและทำงานได้ปกติ ไม่อยู่ในเงื่อนไขคืนเงิน
- ขอคืนเงินได้ภายใน 7 วันนับจากวันรับเครื่อง พร้อมใบเสร็จ

## นโยบาย P04 ราคาและส่วนลด
- ร้านใช้ราคามาตรฐานตามที่ประกาศในคลังความรู้นี้เท่านั้น
- **ร้านไม่มีโปรโมชันส่วนลด ไม่รับต่อราคา และไม่มีบริการซ่อมฟรีนอกจากการตรวจเช็คอาการ**
- พนักงานหรือแชทบอทไม่มีสิทธิ์ให้ส่วนลดหรือเปลี่ยนราคา

## นโยบาย P05 ความเป็นส่วนตัวและข้อมูลลูกค้า
- ร้านไม่เปิดเผยข้อมูลลูกค้า (ชื่อ เบอร์โทร ที่อยู่ ประวัติการซ่อม) ให้บุคคลอื่นทุกกรณี
- ช่างไม่เปิดดูไฟล์ส่วนตัวของลูกค้าเกินความจำเป็นในการซ่อม
- แชทบอทไม่มีสิทธิ์เข้าถึงฐานข้อมูลลูกค้า สอบถามสถานะงานซ่อมของตนเองได้ทางโทรศัพท์โดยแจ้งเลขใบรับเครื่อง

## นโยบาย P06 การชำระเงิน
- รับเงินสด โอนเงิน และ PromptPay
- ยังไม่รับบัตรเครดิต และไม่มีบริการผ่อนชำระ
- ชำระเงินเมื่อรับเครื่องคืน (ยกเว้น Remote Support ชำระก่อนเริ่ม)

## นโยบาย P07 การรับเครื่องคืน
- ร้านแจ้งลูกค้าเมื่อซ่อมเสร็จทางโทรศัพท์หรือ LINE
- กรุณารับเครื่องคืนภายใน 30 วันหลังแจ้งซ่อมเสร็จ เกินกำหนดร้านไม่รับผิดชอบความเสียหาย

## นโยบาย P08 การจองคิว
- จองคิวล่วงหน้าได้ทางโทรศัพท์หรือ LINE OA ไม่มีค่าจอง
- Walk-in ได้ทุกวันในเวลาทำการ
- บริการ On-site ต้องนัดล่วงหน้าอย่างน้อย 1 วัน

## บริการที่ร้านไม่ให้บริการ (นอกขอบเขต)
- ไม่ซ่อมโทรศัพท์มือถือ แท็บเล็ต และสมาร์ตวอทช์
- ไม่ซ่อมเครื่องใช้ไฟฟ้าอื่น (ทีวี เครื่องเสียง)
- ไม่ซ่อมเมนบอร์ดระดับชิป (Chip-level)
- ไม่จำหน่ายคอมพิวเตอร์เครื่องใหม่
- ไม่ติดตั้งซอฟต์แวร์ละเมิดลิขสิทธิ์ ไม่ปลดล็อกรหัสผ่านของเครื่องที่ลูกค้าไม่ได้เป็นเจ้าของ และไม่ช่วยเจาะระบบ / แฮกรหัส Wi-Fi ของผู้อื่น
- คำถามที่ไม่มีข้อมูลในคลังความรู้นี้ ให้ตอบว่า "ขออภัยครับ ข้อมูลนี้อยู่นอกเหนือขอบเขตที่ระบบตอบได้ กรุณาติดต่อร้านโดยตรงที่ 02-123-4567"

## การจับคู่ภาพ / ข้อความ Error กับบริการ (ใช้กับ Vision)
| สิ่งที่เห็นในภาพ / ข้อความ Error | บริการที่แนะนำ |
|---|---|
| จอฟ้า "Your PC ran into a problem", STOP CODE, BSOD | S03 (เริ่มต้น 800 บาท) |
| "No Bootable Device", "Boot Device Not Found", "Operating System not found" | S01 ตรวจเช็คฟรี แล้วอาจเป็น S02 หรือ S12 |
| "Disk 100%" ใน Task Manager, เครื่องช้ามาก | S12 (เปลี่ยนเป็น SSD) หรือ S11 |
| จอแตก จอเป็นเส้น จุดดำบนจอ | S08 (ค่าแรง 500 บาท ไม่รวมอะไหล่) |
| ปุ่มคีย์บอร์ดหลุด / หาย | S05 (เริ่มต้น 300 บาท) |
| Router ไฟแดง / ไฟ LOS กะพริบ | S09 (800 บาท) หรือแนะนำติดต่อผู้ให้บริการอินเทอร์เน็ต |
| ป๊อปอัปโฆษณาเยอะ, แจ้งเตือน "Your computer is infected" ปลอม | S11 (400 บาท) |
| ไฟล์นามสกุลแปลก + ข้อความเรียกค่าไถ่ (Ransomware) | S11 และ S04 (ไม่รับประกันการกู้ไฟล์) |
| ไอคอนแบตเตอรี่ "plugged in, not charging", แบตบวม | S13 หรือ S18 |
| "Printer Offline", "Driver is unavailable" | S16 (300 บาท) |
| ภาพมือถือ / แท็บเล็ต | นอกขอบเขต ร้านไม่ซ่อมมือถือและแท็บเล็ต |
| ภาพไม่เกี่ยวกับอุปกรณ์ไอที หรือไม่ชัด | ขอให้ลูกค้าส่งภาพใหม่ที่เห็นข้อความ Error ชัดเจน |

## คำถามที่พบบ่อย (FAQ)
1. ร้านเปิดกี่โมง → ทุกวัน 10:00–20:00 น.
2. ตรวจเช็คอาการเสียเงินไหม → ฟรี ไม่ซ่อมไม่มีค่าใช้จ่าย
3. ลง Windows ราคาเท่าไหร่ → 500 บาท พร้อมไดรเวอร์
4. จอฟ้า / เปิดไม่ติด ซ่อมได้ไหม → ได้ เริ่มต้น 800 บาท
5. กู้ข้อมูลที่ลบไปได้ไหม → ได้ เริ่มต้น 1,000 บาท กู้ไม่ได้ไม่เก็บเงิน
6. คีย์บอร์ดพิมพ์ไม่ติด → ซ่อมได้ เริ่มต้น 300 บาท
7. ให้ช่างรีโมทดูได้ไหม → ได้ ผ่าน AnyDesk 250 บาท/ครั้ง
8. ซ่อมแล้วมีประกันไหม → ฮาร์ดแวร์ 90 วัน ซอฟต์แวร์ 15 วัน
9. ซื้อ RAM มาเอง ใส่ให้เท่าไหร่ → 200 บาท
10. ซ่อมไม่หายคืนเงินไหม → คืนค่าบริการ 100%
